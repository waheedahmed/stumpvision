# OpenSpec: StumpVision Specifications Index

StumpVision is an elite, offline-first cricket analytics application that integrates real-time computer vision simulation, 3D ball trajectory compilation, sensor snicko-meter analysis, automated Decision Review System (DRS) validation, and Gemini-powered smart coaching feedback.

To adhere strictly to the **OpenSpec directory layout structure**, the documentation has been separated into modular files under the `/specs/` directory:

---

## 📂 OpenSpec Folder Layout & Catalog

* **[Master Spec Index File](/specs/README.md)**  
  The primary entry point mapping all sub-specifications and folder routes.

* **[Proposals Module](/specs/proposals/001_core_proposal.md)**  
  *Path: `/specs/proposals/001_core_proposal.md`*  
  Covers the overall product core value proposition, color pallets, Material 3 design tokens, typography styles, and user interface layouts (Features A through E).

* **[Technical Architecture Module](/specs/architecture/001_technical_spec.md)**  
  *Path: `/specs/architecture/001_technical_spec.md`*  
  Details database layouts (Room schemas for `sessions` and `deliveries`), foreign key cascading constraints, on-device H.264 `MediaCodec` rendering pipeline, and precise Gemini analytical prompts.

* **[Backlog & Tasks Module](/specs/tasks/001_backlog_status.md)**  
  *Path: `/specs/tasks/001_backlog_status.md`*  
  Outlines complete trackable engineering tasks checklists, milestone states, and build validation recipe protocols.
